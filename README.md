# Cognizant Java Deepskilling Program

Welcome to the **Cognizant Java Deepskilling** repository! This repository contains all the hands-on exercises, assignments, and module implementations completed as part of the Cognizant Java Deepskilling curriculum.

---

## 📌 Repository Overview

The repository is structured week by week, following the curriculum progression from core Java fundamentals to advanced full-stack technologies like Spring Boot and Angular.

| Module / Week | Description | Primary Tech Stack |
| :--- | :--- | :--- |
| **Week 1** | Core Java, Design Patterns, Logging (SLF4J) | Java, SLF4J |
| **Week 2** | Database Connectivity & ORM / Advanced Java | Java, JDBC / Hibernate |
| **Week 3** | Spring Framework & Spring Boot Basics | Java, Spring Boot |
| **Week 4** | RESTful Web Services & Spring Data JPA | Spring Boot, Spring Data JPA |
| **Week 5** | Frontend Development with Angular | Angular, TypeScript, HTML/CSS |
| **Week 6** | Unit Testing, Code Quality & Best Practices | JUnit, Mockito |

---

## 🛠️ Tech Stack & Prerequisites

Before running any of the projects, ensure you have the following installed:

* **Java Development Kit (JDK):** Version 11 or higher
* **Node.js & npm:** (For Angular hands-on modules in Week 5)
* **Angular CLI:** `npm install -g @angular/cli`
* **Build Tool:** Apache Maven or Gradle
* **IDE:** IntelliJ IDEA / Eclipse / VS Code
