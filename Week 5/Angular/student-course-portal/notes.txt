angular.json
Project configuration file.

package.json
Contains project dependencies and scripts.

tsconfig.json
TypeScript compiler configuration.

tsconfig.app.json
TypeScript settings for application.

src/main.ts
Application entry point.

src/app/app.ts (or app.component.ts)
Root component.

src/app/app.config.ts
Application configuration.

src/index.html
Main HTML page loaded by browser.
